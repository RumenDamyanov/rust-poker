# Poker Glossary

Common poker terms used in the rust-poker engine.

---

| Term | Definition |
|------|------------|
| **All-In** | Betting all remaining chips |
| **Ante** | A forced bet placed by all players before the hand |
| **Big Blind** | A forced bet placed by the player two seats left of the dealer |
| **Bring-in** | A forced bet in stud games, made by the player with the lowest face-up card |
| **Button** | The dealer position marker; rotates clockwise each hand |
| **Call** | Matching the current bet to stay in the hand |
| **Check** | Passing without betting (only when no bet is outstanding) |
| **Community Cards** | Shared cards in the center of the table (Texas Hold'em, Omaha) |
| **Dealer** | The player at the button position; deals rotate clockwise |
| **Draw** | The phase where players discard and replace cards (Five-Card Draw) |
| **Flop** | The first three community cards dealt at once |
| **Flush** | Five cards of the same suit |
| **Fold** | Discarding your hand and forfeiting the pot |
| **Four of a Kind** | Four cards of the same rank |
| **Full House** | Three of a kind plus a pair |
| **Hand** | A single round of play from deal to showdown |
| **Heads-Up** | A game with only two players |
| **High Card** | A hand with no pairs or other combinations |
| **Hole Cards** | Private cards dealt face-down to each player |
| **Kicker** | A non-paired card used to break ties between equal hands |
| **Main Pot** | The pot that all eligible players can win |
| **Muck** | To discard a hand without showing it |
| **No Limit** | A betting structure with no maximum bet |
| **Omaha** | A variant using 4 hole cards; must use exactly 2 |
| **One Pair** | Two cards of the same rank |
| **Pot** | The total chips wagered in the current hand |
| **Pot Limit** | A betting structure where the max bet equals the current pot |
| **Pre-flop** | The first betting round, before community cards are dealt |
| **Raise** | Increasing the current bet |
| **River** | The fifth and final community card |
| **Royal Flush** | A straight flush from 10 to Ace |
| **Scoop** | Winning both the high and low portions of a split pot |
| **Showdown** | Revealing hands to determine the winner |
| **Side Pot** | A separate pot created when a player goes all-in |
| **Small Blind** | A forced bet placed by the player to the left of the dealer |
| **Straight** | Five consecutive cards of mixed suits |
| **Straight Flush** | Five consecutive cards of the same suit |
| **Stud** | A variant where some cards are dealt face-up |
| **Three of a Kind** | Three cards of the same rank |
| **Turn** | The fourth community card |
| **Two Pair** | Two different pairs |
| **UTG** | Under the Gun — the first player to act pre-flop |
| **Wheel** | The lowest possible straight: A-2-3-4-5 |
